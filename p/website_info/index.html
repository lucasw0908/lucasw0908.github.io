簡單介紹一下

2026-09-02 閱讀時間: 1 分鐘

這個網站是直接用 Hugo 的 Stack Theme 當模板架好的，如同你在網站尾部看到的(想了想其實也沒必要隱藏)，當然有想過自己做一個，但是我現在想到需要的功能也沒有那種需要這麼客製化的。

當然有些自己小修的部分，像是下方的文章數量、翻譯跟 UI 小改，基本上都不值一提。比較有趣的是弄了一個能夠在有新文章時發到 Discord 的 Webhook，但是這東西在這邊也看不到。

留言區的部分原本是用 Disqus，但是那介面真的太醜，所以改成了 Twikoo (截止撰文時還沒測試過，所以也不確定會不會成功)。

之後考慮新增的功能或許也就更好的 Webhook 支援，其他太雜的功能反而不應該出現在簡易的部落格中。
